# Security Policy

## Reporting a Vulnerability

Please do not report suspected security vulnerabilities through public GitHub issues.

For security-related reports, contact:

**security@spactr.com**

Include, where possible:

- a concise description of the issue
- affected component or workflow
- reproduction steps
- potential impact
- relevant logs or screenshots with sensitive information removed

Please do not include credentials, access tokens, personal data, customer data, or other sensitive information in reports.

## Public Showcase Scope

This repository is a curated engineering portfolio showcase rather than the complete private development implementation.

It does not contain production credentials, customer data, private runtime state, proprietary deployment configuration, or the complete commercial platform implementation.

Security-related architecture concepts used by the project are documented in [`docs/security.md`](docs/security.md).

## Responsible Disclosure

Please allow reasonable time to review and address a reported issue before publishing technical details.
